# mcp-mrg-assets

Public logo/favicon assets for the private `mcp-mrg-*` MCP connector family (emrgim).

Each `*.svg` is a square (1:1) logo referenced by the matching private repo's
`.cursor-plugin/plugin.json` `logo` field via an absolute raw URL, so the favicon
renders in Cursor/Grok while the connector source stays private.
